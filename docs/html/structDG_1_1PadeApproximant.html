Detailed Description

template<class Real = double, class Index = int>
struct DG::PadeApproximant< Real, Index >

Stores the [L/M] Padé–Legendre approximant for a single element.

Coefficients are in the unnormalized Legendre polynomial basis. q_coeffs[0] is always 1 (normalization convention).
