Detailed Description

template<class Real = double, class Device = TNL::Devices::Host, class Index = int>
class TNL::DGM::Mesh< Real, Device, Index >

1D DG mesh wrapper providing element geometry and adjacency queries.

Built on top of TNL meshes; provides convenient accessors for element vertices, sizes, jacobians and face neighbour queries used by the DG operator and I/O routines.
